---

## 2. HTML & CSS Rules

All rules from `global.md` apply. Two deltas:

### Font-size unit — `rem`, never `px`

The HTML5 root font-size is reliable and user-scalable. Use `rem` for all font sizes. Do not use `clamp()` — use breakpoints to vary size per viewport instead. `line-height` stays unitless.

### `.cst-page` container — no `box-shadow`

Never implement `box-shadow` on `.cst-page`, even if Figma's page-container node shows one. Treat any container shadow in the Figma spec as an artifact of the standalone mockup frame, not something to reproduce.

## 3. QA

All global QA rules apply. The table below is a checklist of verified and pattern-risk defects from production tickets (AGENCY15-363 / -306). Run through this before every delivery.

| # | What to check | Severity |
|---|---|---|
| 1 | Heading level skip — `<h1>` followed directly by `<h3>`, no `<h2>` | High |
| 2 | `<title>` empty or missing at delivery | High |
| 3 | Footer logo implemented as inline SVG instead of `<img>` | Medium |
| 4 | `:focus` used instead of `:focus-visible` on interactive links | Medium |
| 5 | Font-size declared in `px` instead of `rem` | Medium |
| 6 | Orphaned CSS selectors left after element removal | Medium |
| 7 | Filename case mismatch between `src` and file on disk | Medium |
| 8 | Patch-note CSS block appended instead of merged into original rule | Medium |
| 9 | `box-shadow` on `.cst-page` | Medium |
| 10 | Border width does not match Figma spec (1px vs 2px) | Low |
| 11 | Spacing token used as a font-size value | Low |
| 12 | Unused image files left in `images/` at delivery | Low |

Reference: AGENCY15-306 is the positive example for correct `:focus-visible` implementation.

---

## 4. Delivery

Flat output — no materialization step, no template editable area:

```
index.html
base.css
page.css
images/
```

- Strip all comments from `base.css`, `page.css`, and `index.html` before final delivery.
- Remove unreferenced files from `images/`.
- Confirm all `src` filenames match case on disk.
