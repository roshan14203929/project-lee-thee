# Design skill routing

Project-local skills supplement the Figma workflow. They don't create new state transitions or QA kinds, and can't weaken the source contract, effective guidelines, deterministic checks, or release gates.

## Design Taste during construction

Page builder proceeds directly from normalized spec and effective guidelines.

## Web Interface Guidelines during QA

UI and accessibility reviewers use `guidelines/global/qa/ui-qa.md` and `guidelines/global/qa/accessibility-qa.md` directly.
