# Accessibility QA defaults

Procedures only. The rules live in the coding files delivered alongside this
one; report findings by ID, never restate a rule here.

- Inspect landmarks, heading hierarchy, control names, labels, alt text, keyboard reachability, focus order, focus visibility, reduced motion.
- Check essential hidden responsive content stays reachable.
- Report source selector, user impact, severity, bounded correction.
- Prefer a native-element fix over new ARIA.
- In scope: HTML-007, HTML-011, HTML-012, HTML-013, HTML-014, HTML-015, AM-008, FID-010, FID-011, FID-012.
